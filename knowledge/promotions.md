- Add items to cart
- Go to checkout
- Enter code in "Promo Code" box
- Click "Apply"
- Discount shown in order total

### Promo Code Rules
- One code per order
- Cannot combine multiple codes
- Some exclusions may apply (noted on code)
- Codes have expiration dates
- Case-insensitive (WELCOME10 = welcome10)

### Code Not Working?
- Check expiration date
- Verify minimum order requirement
- Some items may be excluded
- Code may be one-time use
- Contact support if issues persist
