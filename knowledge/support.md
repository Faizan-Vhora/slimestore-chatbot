## Common Issues & Quick Solutions

### Order Not Received
1. Check tracking link in shipping email
2. Verify shipping address was correct
3. Check with neighbors or building office
4. Contact carrier with tracking number
5. Contact us if still not found after 7 days

### Tracking Not Updating
- Tracking updates within 24-48 hours of shipment
- Some delays during carrier processing
- Contact us if no update after 5 days

### Can't Complete Checkout
- Try a different browser
- Clear cache and cookies
- Disable ad blockers
- Try a different payment method
- Contact us if issue persists

### Promo Code Issues
- Check code hasn't expired
- Verify minimum order met
- Ensure items aren't excluded
- Only one code per order

### Website Issues
- Clear browser cache
- Try incognito/private mode
- Update your browser
- Try a different device
- Report persistent issues to support
